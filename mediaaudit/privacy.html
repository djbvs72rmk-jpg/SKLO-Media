Privacy Policy — MediaAudit rclone

Effective date: 24 September 2026

Scope

MediaAudit rclone is a private, personal-use integration operated by its owner to synchronize the owner's MediaAudit files between Google Drive and the owner's server.

Google user data accessed

The integration may access files and file metadata in the owner's Google Drive as needed to perform the owner's synchronization workflow.

How data is used

Google user data is used only to copy, verify, and synchronize MediaAudit distribution files, completed results, handoff evidence, and related metadata between Google Drive and the owner's server.

Storage and retention

Files may remain in the owner's Google Drive and on the owner's server according to the owner's MediaAudit storage and retention workflow. The integration does not create a separate commercial user database.

Sharing and sale

Google user data is not sold, rented, used for advertising, or shared with third parties by this integration.

Security

Access is limited to the owner's Google account and server credentials. OAuth credentials are used only to authorize the owner's synchronization process.

User control

The owner can revoke the integration's Google account access at any time through Google Account security settings and can remove synchronized files from the relevant storage locations.

Contact

Questions about this privacy policy can be raised through the SKLO Media repository on GitHub.
