Незалежні за задумом.

Сімейство поєднує продукти через визначені інтерфейси. Воно не вимагає спільного коду, середовища виконання або одночасного випуску всіх програм.

Кожному — своє завдання

Окремий інструмент можна розвивати для його задачі. Належність до сімейства не робить усі інші продукти обов’язковими.

Взаємодія за контрактом

Формати результатів та інтерфейси узгоджуються явно. Спільна папка або внутрішній файл не стають публічним API автоматично.

Чесно про готовність

Запланована можливість, робочий інструмент і загальнодоступний випуск — різні речі. Межі й стан описуються для кожного продукту окремо.
