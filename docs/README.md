## Documentation model

SKLO Media is modular.

Public documentation may describe shared boundaries and integration rules, while each product keeps its own owner, release lineage, implementation decisions, and acceptance.

Product-specific pages are maintained by the corresponding product owners.

## Current repository role

This repository is a public coordination and documentation entry point.

It is not a declaration of:
- one monorepo;
- one shared runtime;
- one central database;
- one mandatory gateway;
- one shared release line.
